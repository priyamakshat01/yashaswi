HOW TO VIEW THE WEBSITE:
------------------------------------------------------------------------
1. Open your file manager (Dolphin) and go to:
   Documents -> Gift website
2. Double-click on "index.html". It will open right in your web browser!
3. You can also right-click "index.html" -> Open With -> Firefox (or your favorite browser).

   and link them in about.html!
